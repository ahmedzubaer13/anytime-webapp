# Anytime

Real-time expert marketplace prototype: describe a problem, find an available teacher, start a live session, and pay by the minute.

## Run
npm install
npm run dev

## Build
npm run build

## Deploy
Vite + React app. Deploy from GitHub to Vercel, Netlify, or GitHub Pages.

The current app is frontend-only. Authentication, database persistence, real-time presence, video/chat, and real payment processing still need backend integrations for production.
